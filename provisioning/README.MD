## Using the example provisioning

To use the Sift datasource and example dashboard:

1. Create a `.env` file in the project root directory with `SIFT_API_URL` and `SIFT_API_KEY` environment variables
2. Run `docker-compose up -d`
3. Visit http://localhost:3000
4. Verify Sift datasource is configured with API URL and API Key
5. View the sample dashboard
